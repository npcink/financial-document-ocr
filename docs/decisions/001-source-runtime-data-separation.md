# ADR-001：源码、密钥与运行数据分离

## 状态

Accepted

## 日期

2026-07-21

## 背景

财务 OCR 服务同时处理可公开的应用代码、访问云端模型所需的密钥，以及可能含有个人和财务信息的运行数据。把这些内容放在同一版本控制或备份边界中，会使源码协作、公开发布和运行数据保留互相牵制。

## 决定

- Git 只保存源码、文档、无密钥配置模板和可重建的依赖锁文件。
- 密钥只通过被忽略的环境文件或外部 Secret 管理系统提供。
- SQLite、上传件、导出件和运行日志保存在独立数据边界中，并单独加密、授权和设置保留期限。
- 源码备份脚本必须拒绝密钥、数据库、业务文档和构建产物。
- 公开发布前运行自动敏感信息检查，并从新的干净 Git 历史发布。

## 后果

- 源码仓库可以独立审计和公开，不携带运行数据。
- 部署与恢复需要分别处理代码、密钥和数据。
- Git 历史不能作为业务数据或密钥备份。
- 运行环境仍需单独实施身份认证、网络访问控制和数据合规措施。
